Dial 使用指南

{% include dial-guide/byline.html %}

你可以將既有的 GLP-1 用藥紀錄帶進 Dial，不必逐筆重新輸入。iPhone 上的 Dial 1.3.4 及後續版本提供免費 CSV 匯入。儲存前，預覽會顯示 Dial 能讀取的紀錄。匯入不需要 Dial 帳號或 Dial Pro。

請保留原始匯出檔。匯入只會轉入 Dial 能辨識的紀錄，無法保證完整重現原 App 的所有欄位或設定。

開啟檔案並核對預覽

  1. 將既有紀錄儲存為 iPhone 上的 CSV 檔案。
  2. 在 Dial 開啟「設定」，進入「體重與連線」，點選「從其他 App 匯入」，再選擇 CSV 檔案。也可以從「檔案」App 或分享選單用 Dial 開啟 CSV。
  3. 檢查「欄位」區段。每個欄位會顯示標題、範例值，以及 Dial 將讀取的紀錄類型。若對應錯誤，請調整欄位選項。
  4. 將「前幾列」與原始檔案比對，確認藥物、劑量、日期、時間，以及體重或副作用紀錄。
  5. 閱讀欄位上方的數量與提示。確認符合預期後點選「匯入」；若不想儲存，點選「取消」離開預覽。

必須有日期欄位及至少一筆可讀取的紀錄，才能點選「匯入」。預覽只顯示前五列有紀錄的資料，不是整份檔案。匯入後仍應檢查歷史紀錄。

Dial 能讀取哪些 CSV 欄位？

Dial 能辨識 Date、Time、Medication、Dose、Unit、Site、Taken、Weight、Side effects、Severity 和 Notes 等標題，不區分大小寫。你可以在預覽中修正欄位對應。每種紀錄需要的欄位不同：用藥紀錄需要可讀取的藥物與劑量；體重及副作用紀錄則使用各自的欄位。

檔案必須是 UTF-8 文字，以逗號或分號分隔欄位，並支援以引號括住的欄位。若試算表存成其他格式，請重新匯出為 CSV，不要只更改副檔名。Dial 接受最大 25 MB 的檔案。

匯入前確認日期與單位

使用 2026-10-16 這類明確日期，可避免月份與日期順序混淆。Dial 也能讀取常見的數字日期格式與 ISO 8601 時間戳記。遇到順序不明的日期時，會先參考檔案中的線索；沒有線索時，則使用裝置的地區設定。請將預覽與原始紀錄比對。只有日期、沒有可讀取時間的紀錄會設為中午，這只是預設時間，不代表實際用藥時間。

以 mg 或 mcg 記錄的劑量會保留原單位。以 units 或 mL 記錄的資料也會保留原數值與單位，匯入時不會換算成 mg。也請確認體重單位：檔案未指定時，Dial 會使用你在設定中選擇的體重單位。若數值不符，請修正檔案或設定，再重新開啟預覽。

了解數量與未匯入的資料列

預覽會統計藥物、用藥、體重及副作用紀錄，並分別標示已略過的用藥、無法讀取日期的資料列、缺少藥物或劑量的紀錄，以及保留其他單位的劑量。「略過用藥」代表記錄了一次未用藥，與匯入工具無法讀取的資料列不同。

無法讀取日期的資料列不會匯入。請查看完成摘要，確認結果，包括重複或不支援的紀錄。若有缺漏，先比對原始檔案，再新增或修正。匯入只是轉移紀錄，不是漏用藥後的處理建議。

復原匯入

完成摘要提供「復原匯入」。若要移除這次新增的紀錄，請在關閉摘要前使用。它會移除本次匯入新增的藥物、用藥、副作用、提醒與體重紀錄，保留原本已有的紀錄。這是立即復原功能，不是備份，也沒有永久保留的匯入歷程畫面。

確認匯入內容後，可參考用藥紀錄指南（英文），了解如何新增紀錄、修正錯誤及整理要分享的資料。

哪些功能免費？哪些需要 Pro？

CSV 匯入與手機用藥紀錄免費。免費版包含一種藥物及一個提醒，用藥紀錄筆數不限。Dial Pro 提供圖表、PDF 報告、CSV 匯出及 Apple Watch 用藥記錄。匯入檔案與匯出報告是不同功能。

Dial 在你的裝置上讀取檔案。可選用的用藥紀錄同步使用你自己的私人 iCloud 資料庫；體重紀錄另外儲存在裝置本機。隱私權政策說明這些資料的儲存範圍。

Dial 記錄你輸入的內容，不會開立藥物或建議劑量。若檔案或預覽有問題，請聯絡Dial 支援，並避免傳送不願分享的健康資料。
